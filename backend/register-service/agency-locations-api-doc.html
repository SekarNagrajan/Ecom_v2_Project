🌐 Agency Locations API Documentation

🚀 Quick Info: This is a public API endpoint that provides all agency locations (ports with agency codes) from the reportdb database. No authentication required!

📋 Endpoint Overview

GET /api/v1/register/agency-locations

🎯 Purpose

Returns all distinct ports and agency codes from the reportdb database. The API uses intelligent fallback logic to ensure data availability even when the primary data source has issues.

✨ Key Features

  • No Authentication: Public endpoint, no JWT token required
  • Smart Fallback: Automatically tries primary query first, falls back if empty
  • Complete Results: All data returned in one response (no pagination)
  • Read-Only: Safe database access with no side effects
  • Auto-Deduplication: Removes duplicate (portCode, agencyCode) combinations

📥 Request Parameters

This endpoint does not accept any parameters. It returns all agency locations.

📤 Response Format

{ "data": [ { "portCode": "INNSA", "portName": "Nhava Sheva", "agencyCode": "INDMUM" }, { "portCode": "AEJEA", "portName": "Jebel Ali", "agencyCode": "AEJEA1" } ] }

📊 Response Codes

Status Code Description Response Type
200 OK Success - Returns agency locations data AgencyLocationListResponse
500 Internal Server Error Database error or system failure ErrorResponse

🔧 Usage Examples

Get All Agency Locations

curl -X GET "https://api.company.com/ecomapi-service/api/v1/register/agency-locations"

🔍 Database Logic

⚙️ Smart Query Fallback:
  1. Primary Query: Joins ports, agency, and agencylocations tables for complete data
  2. Fallback Query: If primary returns 0 rows, uses simplified join without agencylocations table
  3. Deduplication: Automatically removes duplicate (portCode, agencyCode) combinations
  4. Error Handling: Returns standardized error response if database is unavailable
